📱 Demo Flow

  1. Welcome Screen - Click "Get Started"
  2. Bank Connection - Enter any credentials and click "Connect Securely"
  3. Permissions - Review permissions and click "Confirm & Continue"
  4. Dashboard - View balance, income/expenses, and AI insights
  5. Navigation - Use bottom tabs to explore different sections

🌐 GitHub Pages Setup

To host this demo on GitHub Pages:

  1. Push this code to a GitHub repository
  2. Go to Settings → Pages
  3. Select source branch (usually main or gh-pages)
  4. Set folder to / (root)
  5. Your demo will be available at: https://username.github.io/repository-name/src/
