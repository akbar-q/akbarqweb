# Financially Fluent - Demo App

A modern, mobile-first financial management web application demo built to match the provided mockup designs.

## Features

### 🎨 Modern Design
- Blue gradient theme matching the mockups
- Mobile-first responsive design (375px width optimized)
- Glass morphism effects and smooth animations
- Professional typography and spacing

### 📱 Complete Demo Flow
1. **Welcome Screen** - App introduction with "Get Started" call-to-action
2. **Bank Connection** - Secure bank login with Tarabut Gateway simulation
3. **Permissions** - Review app permissions before granting access
4. **Dashboard/Home** - Main financial overview with balance, income/expenses, and AI insights
5. **Spending Breakdown** - Detailed category breakdown with donut chart visualization
6. **Transactions** - Complete transaction history with realistic UAE data

### 💳 Sample Data
- Current Balance: AED 12,450.75
- Monthly Income: +AED 8,500
- Monthly Expenses: -AED 5,280
- Spending categories: Dining (35%), Shopping (25%), Transport (18%), Bills (14%), Other (8%)
- Realistic transaction data from UAE companies (Zomato, Carrefour, DEWA, Uber, etc.)

This is a fully functional static demo designed for GitHub Pages hosting.

## Getting Started

To get started with the Financially Fluent Demo, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/financially-fluent-demo.git
   ```

2. Navigate to the project directory:
   ```
   cd financially-fluent-demo
   ```

3. Open the `src/index.html` file in your web browser to view the application.
